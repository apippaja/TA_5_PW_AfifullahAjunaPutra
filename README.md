alcPro - Kalkulator Modern dengan Fitur Lengkap
Overview:
CalcPro adalah aplikasi kalkulator interaktif yang dikembangkan dengan HTML, CSS, dan JavaScript. Project ini menawarkan pengalaman penggunaan kalkulator yang modern, intuitif, dan penuh fitur dengan antarmuka yang elegan dan responsif.

Fitur Utama:
🧮 Fungsi Kalkulator Dasar:
Operasi aritmatika lengkap (+, -, ×, ÷)

Input angka 0-9 dan titik desimal

Tombol Clear (C) dan Clear Entry (CE)

Sistem perhitungan berantai dengan urutan operasi yang benar

💾 Fungsi Memori:
M+: Menambah nilai ke memori

M-: Mengurangi nilai dari memori

MR: Memanggil nilai dari memori

MC: Menghapus memori

📊 Fitur Lanjutan:
Riwayat Perhitungan: Menyimpan 5 perhitungan terakhir

Dukungan Keyboard: Bisa dioperasikan menggunakan keyboard

Error Handling: Penanganan error untuk pembagian dengan nol

Responsive Design: Tampilan optimal di desktop dan mobile

Keunggulan Teknis:
🔧 Fungsi Perhitungan:
Mengikuti hirarki matematika yang benar (perkalian/pembagian sebelum penjumlahan/pengurangan)

Mendukung perhitungan berantai: 5 + 3 × 2 = 11 (bukan 16)

Hasil hanya muncul setelah tombol "=" ditekan

🎨 Desain Interface:
Minimalis & Modern: Desain bersih dengan warna netral dan aksen biru profesional

User Experience: Tombol dengan feedback visual, spacing yang nyaman

Professional Look: Tidak terlihat "pasaran" atau berlebihan

Responsive: Beradaptasi dengan berbagai ukuran layar

⚡ Teknologi:
HTML5 semantik

CSS3 dengan Grid Layout dan custom properties

Vanilla JavaScript ES6+ tanpa dependency external

Modular Code yang mudah dipahami dan dikembangkan

Cara Penggunaan:
🖱️ Melalui Mouse/Touch:
Klik tombol angka untuk input

Pilih operator untuk perhitungan

Tekan "=" untuk mendapatkan hasil

Gunakan tombol memori untuk penyimpanan nilai

⌨️ Melalui Keyboard:
Angka 0-9: Input angka

Operator: +, -, *, /

Enter/=": Menghitung hasil

Escape: Clear semua

Backspace: Clear entry
